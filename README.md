# Materialele orelor · 9E și 11P1 · 2026–2027

Site: https://beldugan.github.io/lectii/

- `index.html` – lista orelor pe clase, module și săptămâni (cu „Următoarele 7 zile”).
- `o.html?o=<id>` – pagina unei ore: PDF-ul afișat direct, „Descarcă PDF”, „Printează”, „Ecran complet” și, la orele cu evaluare, „Test + barem” (PDF protejat cu parolă).
- `pdf/` – pachetele generate (copertă + proiectul de lecție + paginile din manual / caietul de practică).
- `data/ore.json` – legătura dintre orele din Google Calendar și pachete.
- `build/build.py` – scriptul care reface pachetele din folderul „Planificari si Manuale 2026 2027”.

Dacă modifici un manual sau un proiect de lecție, pachetele se refac cu același script; adresele orelor rămân aceleași.
